# 产品路线图

[English](product-roadmap.md) · **简体中文**

最后复核：2026-11-23 · 当前版本：**1.19.15**

本文说明今天已经有什么、哪些是刻意不做、下一步计划什么。它是产品范围的唯一事实来源，`README.md` 的能力描述应与这里保持一致。

## 定位

SciFlow 是一个**本地优先、单机运行**的科研工作台。整条数据链都在一个 SQLite 文件里。模型端点和密钥由你自己提供，不向任何由我们运营的服务上传数据。

决定范围的设计原则：

- **本地优先。** 一个 SQLite 文件，没有外部数据库、没有多租户服务、没有账号体系。密钥加密落库。
- **该确定的地方不用概率。** 质量分与引用审计由规则计算，同一段文本永远得到同一个分数和指纹。模型可以提建议，但不决定通过与否。
- **不假装。** 无法验证的集成就写成已知缺口，不伪造成功状态。文献库为空时禁用引用标记，而不是让模型编造。
- **可组合，不堆巨石。** 检索、质量审计、引用审计和地址策略都是共享包，API 与 CLI 共用。
- **用生态。** 编排用 LangGraph，模型传输用 Vercel AI SDK，数据访问用 Drizzle，向量用 sqlite-vec。我们写科研领域逻辑，不重复造基础设施。

## 刻意不做

- **多租户 SaaS。** 不做托管账号、共享存储或组织级计费。
- **协作 UI 与插件市场。** JWT 模式按 owner 隔离数据，但本仓库不做邀请、共享项目、评论区、付费插件列表或签名交易市场。本地扩展资产是工具箱，不是应用商店。
- **出版社自动化。** 不做登录态抓取投稿系统，也不后台轮询编辑部邮箱。工具整理用户已经有的东西。
- **下载付费墙全文。** 只处理元数据。
- **模型托管。** 我们接厂商，不提供权重服务。

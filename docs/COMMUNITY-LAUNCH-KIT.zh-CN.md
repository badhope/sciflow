## 一句话

大多数 AI 科研工具停在“帮你读论文、写综述”；SciFlow 往下再走一步：给它一个研究问题，它自己提假设、写协议、在沙箱里跑实验、被 Critic 驳回后改方案，最后把结论、证据和投稿包一起留在本地。

## 核心卖点（发稿时任选三条，不要全堆）

1. **全自动研究循环，不是一次性问答。** PI → 专家门禁 → 沙箱实验 → Critic → 修订回边；AI 专家驳回后会自动重写协议，最多两版，仍不过才停。
2. **断点真的能续。** 服务被 `kill -9` 后重启，审批中的循环仍停在审批，执行中的循环从 checkpoint 继续；20 轮并发 + 5 个边界场景压测 25/25 通过。
3. **数据留在本机。** 一个 SQLite 文件装下项目、文献、实验、结论、投稿包；模型端点自己配，不强制上云。
4. **结论可审计。** 每条 claim 对应 run、stdout、证据；引用检查会把幽灵引用打成红牌，不靠“看起来像”。
5. **投稿不是终点。** 七维质量评审、投稿就绪检查、ZIP 投稿包、Cover Letter 都能在同一个工作台里完成。

## 五个平台怎么发

### 1. 知乎

- 标题：**《我给科研 Agent 加了一条“被驳回就重写”的回边，它终于不像个只会顺从的助手了》**
- 开头：先讲一个真实翻车——第一版实验者把“二维晶格热导率”写成了通用的误差/不确定性相关性，Critic 直接判“严重偏离原问题”。再讲怎么把专家驳回变成下一版协议的设计输入。
- 配图：`docs/screenshots/programs.png`、`docs/screenshots/quality.png`
- 结尾：放仓库地址与基线文档，不写“求 star”，写“如果你也在做长跑 Agent，欢迎拿压测脚本去打”。
- 发布检查：登录态、盐选/专栏选择、外链白名单。

### 2. 稀土掘金

- 标题：**《长跑 Agent 的崩溃点不在 Prompt，在状态机》**
- 结构：问题（重启后 `running` 锁残留）→ 现场（`kill -9` 日志）→ 方案（启动恢复、心跳看门狗、execute 重放幂等、预算前置门禁）→ 证据（25/25 压测、真实重启两例 PASS）→ 代码位置。
- 配图：一张架构/状态机图 + 一张压测结果表；不要放聊天截图凑数。
- 标签：`Agent`、`LangGraph`、`SQLite`、`开源`。
- 发布检查：掘金编辑器 Markdown 兼容、代码块语言标记、封面 1200×800。

### 3. CSDN

- 标题：**《从 0 到 1 做一个本地优先的 AI 科研工作台：架构、踩坑与压测》**
- 定位：教程向，允许长。按“数据层 / 模型层 / 研究循环 / 质量门 / 投稿包”五段拆，每段给目录与关键代码路径。
- 配图：`docs/screenshots/dashboard.png`、`docs/screenshots/knowledge.png`、`docs/screenshots/submission.png`。
- 发布检查：原创声明、分类 `人工智能`、不要勾选 GitCode 备份开关（按既定偏好保持关闭）。

### 4. 博客园

- 标题：**《一个 SQLite 文件，装下一整轮科研》**
- 风格：更技术、更克制。讲为什么不上 Postgres/向量数据库集群，讲单文件带来的备份、迁移、审计便利，也讲它的边界（并发上限、嵌入维度迁移）。
- 配图：`docs/screenshots/knowledge.png` + 数据库表关系图。
- 发布检查：博客园 Markdown 代码块、摘要长度、首页候选。

### 5. B 站

- 标题：**《让 AI 自己跑一轮科研：提假设、跑实验、被驳回、改方案》**
- 形式：3–5 分钟屏录，不露脸。顺序：新建研究问题 → PI 出协议 → AI 专家驳回 → 自动重写 → 沙箱执行 → Critic 结论 → 质量门 → 投稿包。
- 配图/封面：`docs/screenshots/programs.png` 裁成 16:9，标题不超过 12 字。
- 简介：仓库地址 + 基线文档 + “ mock 压测 25/25，真实模型试跑记录在 `docs/verification/assets/`”。
- 发布检查：实名认证、创作声明（含 AI 生成内容需标注）、合集分类。

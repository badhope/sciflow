# SciFlow 品牌指南（Brand Guidelines）

> 版本 2.0 · 2026-11-03
> 本指南是 SciFlow 品牌视觉的唯一事实来源。所有端（Web / 桌面 / 文档 / 周边物料）一律遵循本规范。
>
> **2.0 为什么推倒重来**：1.x 的「渐变圆角方底 + 白色弧线 + 轨道环 + 节点圆点」与市面上
> 大量 AI 产品的图标同构，渐变 + 玻璃 + 辉光的界面语言也一样——用户看到的第一眼是
> 「又一个 AI 工具」，而不是 SciFlow。2.0 回到这个产品真正的身份：**科研工作台**。
> 中国学术批注的传统里，审阅、评定、定稿都落在**朱砂**上；论文写在**纸**上，字是**墨**，
> 界面主色取**黛蓝**（冷静、可信，但不是 Tailwind 默认蓝）。全品牌没有渐变彩虹、
> 没有辉光滤镜、没有轨道与节点——印章的干脆就是辨识度。

---

## 1. 品牌 Core

| 项 | 内容 |
|---|---|
| 名称 | SciFlow（Sci + Flow），连写、S/F 大写；不写 Sci-flow / sciflow / 思流 |
| 中文定位 | 科研全流程工作台 · 让科研从想法到成文 |
| 品牌隐喻 | **朱印**：科研流程走完，落下一个审阅的印记。收笔处的一点朱砂是全品牌签名细节 |
| 性格 | 专业、克制、可信、有出处；**明确回避**：多色渐变、玻璃拟态、辉光、轨道节点、紫色系 |

## 2. Logo

### 2.1 构成（朱印 1.0）

- **App 图标**：平涂朱砂 `#BE3B2A` 圆角方底（r≈22%）+ 一笔白文 S + 右下印角留白。
  只有三个形状、两个颜色——印章的逻辑是「刻得动就刻，刻不动就不刻」。
- **独立标志**（浅色底）：黛蓝 `#2F5480` 主笔 S + 收笔一点朱砂。
- **独立标志**（深色/照片底）：纯白主笔 + 提亮朱砂点 `#D4674F`。
- **横版组合**：朱砂印 + 词标「Sci」墨色「Flow」朱砂（字标即印文）+ 标语。
- 一笔 S = 科研全流程一笔贯通；一点朱砂 = 流程走完落下的审阅印记。
- **禁止**：渐变、投影滤镜、发光、把朱点换成圆环、给 S 加轨道/节点。

| 文件 | 用途 |
|---|---|
| `docs/brand/icon-master.svg` | **App 图标母版**（1024×1024），PNG/ICO/ICNS 由此渲染 |
| `docs/brand/logo-mark.svg` | 独立标志（黛蓝主笔 + 朱点），浅色底 |
| `docs/brand/logo-mark-light.svg` | 独立标志（白主笔 + 朱点），深色/照片底 |
| `docs/brand/logo-horizontal.svg` | 横版组合（印 + 词标 + 标语），README/官网/文档封面 |

| `apps/desktop/build/icon.png` | 桌面端安装包图标（由脚本从母版生成） |

再生成位图：`pnpm icons`（内部调用 `scripts/generate-icons.mjs`，基于 resvg 矢量渲染）。

### 2.3 使用规范

- **最小尺寸**：标志 20px；横版组合 220px 宽。
- **安全边距**：标志四周留出 ≥ 1/4 高度的空白。
- **背景**：浅色底用 `logo-mark.svg`（黛蓝版）；深色底/朱砂印底用 `logo-mark-light.svg`（白版）。
- **禁止**：拉伸变形、改笔画粗细、换非品牌色、加阴影/描边/发光滤镜、词标换手写体。

## 3. 色彩

### 3.1 四色体系

```
纸  #F5F4F0   暖白底（应用背景、大面积留白）
墨  #262B33   近黑正文（标题、正文）
黛  #2F5480   主色（按钮、链接、选中、聚焦）——蓝灰调，不是科技蓝
朱砂 #BE3B2A  签名点睛（印底、Flow 词标、运行态收笔点）——克制使用，一屏一处
```

暗色「墨夜」：底 `#101318`（近黑微暖）、正文 `#E6E4DE`（暖白）、黛提亮 `#7FA3CC`、朱砂提亮 `#D4674F`。

### 3.2 Token 对照表（与 `apps/web/src/index.css` 一一对应）

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--brand-400/500/600` | #7090b4 / #47719e / #2f5480 | 提亮档 | 强调色、聚焦环、边框 |
| `--brand-700` | #234367（白底 8.5:1） | #a5c0e0 | 正文级品牌文字 |
| `--brand-seal-light` / `--brand-seal-on-dark` | #be3b2a / #d4674f | — | 朱砂签名色（印底、朱点、Flow 词标） |
| `--on-brand` | #f7fafd | #f2f6fb | 品牌底上的文字 |
| `--brand-grad` | 黛蓝同相两档微差 | 提亮版 | 主按钮、导航高亮——**读作平涂**，禁止恢复多色渐变 |
| `--brand-grad-soft` | 4%–9% 黛蓝透明度 | 更低 | 区块氛围底、选中淡底 |
| `--brand-glow` | 单层 14% 投影 | 黑系投影 | 仅 hover 出现，禁止常驻发光 |
| `--card-shadow` | 双层卡片阴影 | 深色版 | 所有 Card |
| `--bg-app` / `--background` | #f5f4f0 | #101318 | 应用背景 |
| `--ink` / `--foreground` | #262b33 | #e6e4de | 正文墨色 |
| `theme-color`（meta） | #f5f4f0 | #101318 | 由 `applyTheme()` 按 风格 × 明暗 写入 |
| `--color-teal-*` | **整段重映射为黛蓝阶** | 暗色黛蓝阶 | 兼容历史 `teal-*` 工具类（换色不改类名） |

### 3.3 语义色

- 成功/保存：emerald 系；警示：amber 系；错误：rose 系（Tailwind 默认语义，不另造色板）
- **朱砂不是错误红**：它是品牌签名色，只出现在品牌位置（印底、朱点、词标）；
  界面语义里的危险/报错一律走 rose，二者不同色值、不同职责。

### 3.4 图表系列色（`--viz-series-1..6`）

黛蓝 → 朱砂 → 苔绿 → 赭石 → 石青 → 灰。学术图表气质：低饱和、可区分、不打架。

## 4. 字体

| 场景 | 字体栈 |
|---|---|
| 界面正文 | `-apple-system, "Segoe UI", "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", sans-serif`（零网络依赖） |
| 长文阅读 | Iowan Old Style / Georgia / 宋体系衬线（`--font-read`） |
| 代码 / kbd | `ui-monospace, SFMono-Regular, Menlo, monospace` |
| 词标（横版 Logo） | 同界面字体栈，weight 700，字距 -0.5 |

> 原则不变：**不引入网络字体**。前端体积红线高于字体美学。

## 5. 品牌组件类（CSS 契约）

| 类 | 用途 | 2.0 变化 |
|---|---|---|
| `brand-logo` | 朱砂印底徽标（侧栏、关于页、步骤徽章） | 渐变底 → 平涂朱砂，恒定不随主题变色 |
| `brand-btn` | 主按钮 | 多色渐变 → 黛蓝同相两档微差；常驻发光已删 |
| `brand-gradient-text` | 渐变文字裁切（存量调用兼容） | 现渲染为黛蓝同相微差；新代码**禁止使用**，词标用 `--brand-seal-*` |
| `nav-active` | 侧边导航活跃项 | 同主按钮处理 |
| `brand-breathe` | 运行态呼吸点 | 保留，色走 `--brand-500` |
| `glass-header` | 顶栏 | 保留但降低模糊/饱和（saturate 1.15） |
| `card-lift` / `card-glow` | 交互卡 hover | 保留，阴影走中性墨色 |
| `input-focus-ring` / focus-visible | 聚焦环 | 黛蓝 |
| `page-in` / `modal-in` / `toast-in` | 入场动效 | 不变 |

## 6. 动效原则

1. **快而不跳**：入场 150–220ms，缓出优先；
2. **有生命感**：运行态用呼吸/流光表达"在工作"；
3. **克制**：一次只允许一个持续动画元素；`prefers-reduced-motion` 全部退化；
4. **2.0 新增**：禁止装饰性发光与常驻渐变动画——「动」只用于表达状态，不用于表达高级。

## 7. 文案与语调

- **中文为主**，句末不加句号；错误信息一律中文转译，不裸露英文技术词。
- 主标语：**让科研从想法到成文**；不得自行发明新 slogan。
- 自称统一为 **SciFlow**；提及 AI 能力时不夸大：说"辅助生成/辅助润色"，
  不说"全自动替代研究者"。

## 8. 各端落地要求

| 端 | 必须落实 |
|---|---|
| Web | favicon.svg / apple-touch-icon / theme-color `#f5f4f0` / 侧栏朱砂印徽标 / 品牌组件类 / 6 套主题风格包（`styles/themes.css`） |

| 文档 | README 头图用横版组合；截图以「朱印纸墨」亮色为主 |
| 导出物（MD/DOCX/HTML） | 模板页眉/封面可放横版 Logo；文档属性作者写 "SciFlow" |

## 9. 变更流程

品牌资产（本目录、favicon、品牌 CSS token）的任何改动必须：

1. 同步更新本指南版本号与日期；
2. 跑 `pnpm icons` 重新生成全部位图；
3. 在 CHANGELOG.md 记录；
4. 更新 `BrandMark.test.tsx` 契约断言（几何结构锁定，防止改回模板件）；
5. 截图对比桌面端安装包图标与 Web 侧栏，确保同源一致。

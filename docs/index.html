把科研全流程

SciFlow 是本地优先、单机部署的科研全流程 AI 助手：输入一个研究主题，由 LangGraph 编排的多智能体流水线接管，完成文献调研 → 写作 → 质量门 → 投稿辅助的完整生命周期，文献与 Key 全部落本地 SQLite。

🗄️ 本地优先 SQLite 单文件 🤖 多智能体 自动流水线 📊 Recharts + sigma.js 可视化 🔌 OpenAI 兼容 自配模型 Key

三分钟跑起来

要求 Node ≥ 20、pnpm ≥ 9。SQLite 首次启动自动建表，零配置开箱即跑。

1克隆代码
# 任选一个仓库镜像克隆
git clone https://gitcode.com/badhope/sciflow.git sciflow
cd sciflow
2安装依赖
pnpm install
cp apps/server/.env.example apps/server/.env
# 至少填 AI_BASE_URL / AI_API_KEY / AI_MODEL
3构建并运行
pnpm --filter @sciflow/server build
# 终端 A：后端 :3000
node apps/server/dist/apps/server/src/main.js
# 终端 B：前端 :5173
pnpm --filter @sciflow/web dev
# 浏览器打开 http://localhost:5173

接入你自己的模型

SciFlow 只走 OpenAI 兼容协议，填 base_url + model + key 即可；未配置 Key 时本地功能照常可用，AI 不返回假数据。

变量说明示例值（占位）
AI_BASE_URLOpenAI 兼容接口地址https://api.deepseek.com/v1
AI_API_KEY你的 API 密钥sk-your-api-key-here
AI_MODEL默认模型deepseek-chat
AI_MODEL_FAST快档：问答 / 润色 / 翻译留空则回落 AI_MODEL
AI_MODEL_STRONG强档：规划 / 长文起草留空则回落 AI_MODEL
AI_RPM_CAP每分钟调用上限（令牌桶防 429）8（长流水线建议 100+）
AI_MOCK设 1 启用本机 mock 网关1（无 Key 跑全链路）
 
# apps/server/.env（占位示例）
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
AI_API_KEY=sk-your-api-key-here
AI_MODEL_FAST=deepseek-chat
AI_MODEL_STRONG=deepseek-reasoner
AI_RPM_CAP=8

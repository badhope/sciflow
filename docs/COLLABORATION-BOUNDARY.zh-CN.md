# 协作边界

**简体中文** · [English](COLLABORATION-BOUNDARY.md)

最后复核：2026-11-25 · 适用范围：**1.19.18**

这份文档把 SciFlow 里“分享”到底是什么写死。原因是**公开只读快照**和
**团队协作**是两种产品；边界不写清楚，就无法验收，也容易被后续改动悄悄越界。

## 产品模型

SciFlow 是**单机、单一所有者**的科研助手。项目只属于创建它的人；没有成员
模型、组织账号或共享项目数据库。

已经交付的协作面只有一条很窄的路：

1. 所有者可以把**一篇文档**或**一段对话**发布成冻结的只读快照；
2. 任何拿到不可枚举链接的人，无需账号即可阅读；
3. 所有者可以选择允许匿名读者留下**纯文本评论**；
4. 所有者可以隐藏评论（线上按钮叫“删除评论”）、撤销链接，或让链接到期；
5. 除此之外，没有别的协作能力。

## 权限矩阵

| 动作 | 项目所有者 | 链接访问者（无账号） | 同实例其他账号 |
| --- | --- | --- | --- |
| 打开项目工作台 | 可以 | 不可以 | 不可以 |
| 阅读已分享快照 | 可以 | 链接有效时可以 | 链接有效时可以 |
| 编辑源文档 / 对话 | 可以 | 不可以 | 不可以 |
| 创建分享链接 | 可以 | 不可以 | 不可以 |
| 查看评论 | 可以 | 可以（公开页） | 可以（公开页） |
| 发表评论 | 可以 | 仅开启评论时 | 仅开启评论时 |
| 隐藏 / 删除评论 | 可以 | 不可以 | 不可以 |
| 撤销链接 | 可以 | 不可以 | 不可以 |
| 撤销或到期后继续访问 | — | 不可以 | 不可以 |

“同实例其他账号”指同一套 SciFlow 上的第二个账号。它不会因为登录而获得别人项目的
访问权；唯一入口与匿名访客相同：公开链接。

## 什么会进入快照

文档快照只含：

- 标题、Markdown 正文、文档版本、更新时间、项目名称。

对话快照只含：

- 可见的 `user` 与 `assistant` 消息正文；
- 最多 200 条消息，每条最多 50,000 字符；
- 会话标题与项目名称。

对话快照**不包含**附件与文件名、推理或隐藏思考、工具调用与工具结果、系统提示、
消息 ID、token 用量、模型名称及内部元数据。文档快照**不包含**二进制附件或图表，
只冻结文字正文。

快照是不可变的：源文档后续修改不会改变已生成的链接，旧链接也无法反推出新版本。

## 评论规则

- 评论在创建分享时**默认关闭**。
- 开启后评论是匿名的：称呼可选、由读者自填，最多 40 字；正文 2–1,000 字。
- 控制字符与尖括号会被剥离；评论按纯文本呈现，不当作 HTML 或 Markdown 执行。
- 所有者可以在分享弹窗查看评论列表，并逐条隐藏。隐藏是软删除，审计行保留；线上按钮
  文案是“删除评论”，但不会物理删行。
- 没有回复、@、表情、订阅、邮件/推送通知、审核队列或读者统计。
- 公开评论不是私密客服通道。涉及机密或个人材料时不要开启评论。

## 链接生命周期

- Token 为 24 字节随机数的十六进制串，不由项目 ID 或文档 ID 推导，无法枚举。
- 有效期默认 30 天，创建时限制在 1–365 天。
- 撤销立即生效；此后公开读取与评论均失败。到期在每次公开读取时校验。
- 分享地址为 `/share/<token>`；前端渲染前会把裸路径归一化到 hash 路由，因此复制
  到全新浏览器也能打开。

## 明确不做

以下能力不是“做了一半”，而是**范围外**：

- 邀请、成员、角色、RBAC、按用户授权、团队工作区；
- 共同编辑、在线状态、光标、@、动态流；
- 评论盖楼、回复、表情、评论附件；
- 按读者放行、密码、域名限制、水印；
- 读者身份、浏览量、统计、新评论通知；
- 插件市场或付费扩展列表。

要加其中任何一项，都必须重新做产品决策和权限模型，不能把它包装成“分享功能的小优化”
偷偷塞进来。

## 约束落点与验收证据

- 快照生成与脱敏：`apps/server/src/share/share.service.ts`。
- 公开读取、评论与撤销路由：`apps/server/src/share/share.controller.ts`。
- 服务测试：`apps/server/src/share/share.service.spec.ts` 覆盖对话脱敏、评论默认关闭、
  作者隐藏、撤销、到期、跨项目拒绝。
- 前端：`apps/web/src/pages/PublicSharePage.tsx` 与
  `apps/web/src/pages/WorkspacePage.tsx` 的分享弹窗。
- 2026-11-23 浏览器实测：扫描 PDF → 真实模型回答 → 存为文档 → 导出 PDF
  （文本层含答案）→ 开启评论分享 → 公开页显示快照并接受匿名评论。同一次实测
  发现并修复了 `/share/<token>` 裸路径无法打开的问题。
